# 00 — Frontend Scope

## Obiettivo
Realizzare il frontend React del CRM Prestito in Tasca consumando esclusivamente l'API Laravel v1 già congelata.

Il frontend deve essere pronto per una demo locale credibile e riutilizzabile in produzione.

## Admin
Può usare dashboard globale, lead, filtri, dettaglio lead, stati, note, task, utenti, provenienze, operatori per provenienza, ricircoli, pratiche/documenti, sincronizzazioni sito/Meta e mapping Meta.

## Operator
Può usare dashboard personale, propri lead, dettaglio lead assegnati, cambio stato, note, richiami e pratiche/documenti autorizzati.

## Fuori scope
Prodotti, portale cliente, notifiche push/email, analytics avanzati, merge contatti, VPS, modifiche backend, modifiche sito.

## Post-MVP

Le azioni rilevanti del CRM dovranno generare notifiche email al diretto interessato. Il dettaglio evento -> destinatario sarà definito dopo il completamento MVP.
