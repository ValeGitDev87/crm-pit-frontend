# 05 — Design System

Obiettivo: interfaccia professionale per CRM finanziario, non uno scaffold.

Componenti riutilizzabili:
- Button
- Input
- Select
- Checkbox
- Modal
- Badge
- StatusBadge
- Card
- StatCard
- DataTable
- Pagination
- EmptyState
- LoadingState
- ErrorState
- ConfirmDialog
- Toast/Alert

Desktop prioritario per la demo, ma responsive.

Accessibilità minima:
- label form;
- focus visibile;
- button veri;
- modali chiudibili;
- errori associati ai campi.

Non dipendere dal colore soltanto: mostrare sempre testo.
